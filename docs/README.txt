PRJ-0001 AI English Speaking Tutor mobile deliverables

Open the HTML file in a modern browser. Mobile viewport is responsive; navigation, course selection, text evaluation and supported browser speech recognition are interactive.

Important: the HTML is a front-end concept prototype. It does not connect to the Python engine or proposed REST API. Current repository is a CLI-based sentence comparison and rule-based feedback engine; pronunciation scoring, real AI conversation, authentication and payments are not implemented.
